# 📁 Fase 0 — Fundamentos Sólidos

> *"Uma casa sólida começa pela fundação. Não apresse esta fase."*

## 🎯 Objetivo

Construir uma base sólida em Git, HTML, CSS e JavaScript antes de avançar para frameworks. Ao final desta fase, você será capaz de criar páginas web completas, responsivas e acessíveis, com JavaScript moderno.

## 📅 Duração: 8 semanas (Ago–Set 2026)

## 📂 Conteúdo

| Pasta | Tópico | Semana |
|-------|--------|--------|
| `01-git-github/` | Git, GitHub, Terminal, NPM | 1–2 |
| `02-terminal-cli/` | Linha de comando, scripts | 1–2 |
| `03-html-avancado/` | HTML5 semântico, acessibilidade, SEO | 3 |
| `04-css-avancado/` | Flexbox, Grid, animações, responsividade | 4 |
| `05-javascript-core/` | JS completo: ES6+, DOM, Async, Classes | 5–8 |
| `06-typescript/` | Tipagem estática para JavaScript | 9–10 |
