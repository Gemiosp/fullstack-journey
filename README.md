## 🎯 Sobre Esta Jornada

Este repositório documenta minha transição de **Engenheiro de Controle e Automação** (UFOP) para **Desenvolvedor Full Stack**. Cada pasta contém anotações, exercícios e projetos realizados durante o aprendizado.

### Ponto de Partida
- ✅ HTML/CSS básico
- ✅ JavaScript básico
- ✅ Python básico
- ✅ APIs REST (experiência prática)
- ✅ Lógica de programação (engenharia)
- 🔲 Git/GitHub profissional
- 🔲 Frameworks frontend (React, Next.js)
- 🔲 Backend (Node.js, Express, Django)
- 🔲 Bancos de dados
- 🔲 DevOps e Cloud
